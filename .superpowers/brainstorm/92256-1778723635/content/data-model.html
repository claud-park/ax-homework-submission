Data Model

PostgreSQL schema — does this capture everything?

users
id uuid PK (= Supabase auth.user id)
email text NOT NULL
name text
avatar_url text
created_at timestamptz
homeworks
id serial PK → homework number (auto-increment)
title text NOT NULL
description text (HTML from WYSIWYG)
due_date date NOT NULL
created_at timestamptz
submissions
id uuid PK
user_id uuid FK → users.id
homework_id int FK → homeworks.id
file_path text (Supabase Storage path)
file_name text (original filename)
status enum: pending | accepted | declined
attempt_number int (1, 2, 3…)
submitted_at timestamptz
comments
id uuid PK
submission_id uuid FK → submissions.id
body text NOT NULL
created_at timestamptz
Admin-only write · visible to user on their page
FK = foreign key  ·  PK = primary key  ·  attempt_number is derived per (user_id, homework_id) pair — increments on each resubmit  ·  RLS: DENY ALL on all tables (service key only)
