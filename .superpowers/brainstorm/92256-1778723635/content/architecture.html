Auth Flow

👤 User
1. Click "Sign in with Google"
2. Supabase OAuth redirect
3. JWT stored in Supabase session
4. All API calls include JWT header
5. API routes verify JWT → user identity
🔐 Admin
1. Enter email + password on /admin/login
2. Supabase signInWithPassword
3. JWT contains role: admin in metadata
4. API routes check role claim
5. Non-admin JWT → 403 on admin routes
